# Quickstart: 数唱テスト

## 前提条件

- モダンブラウザ（Chrome 90+、Safari 14+、Edge 90+）
- Web Speech APIが使用できる環境（ほぼすべてのモダンブラウザで対応）
- ローカルサーバー不要 — ファイルをブラウザで直接開いて動作する

## 開発環境のセットアップ

```bash
# リポジトリをクローン（またはそのままファイルを開く）
git clone <repo-url>
cd digit-span

# ファイルをブラウザで直接開く（サーバー不要）
# Windows
start index.html

# macOS
open index.html
```

## ファイル構成

```
digit-span/
├── index.html       ← これをブラウザで開く
├── css/
│   └── style.css
└── js/
    ├── app.js       ← メインエントリ・画面制御
    ├── game.js      ← ゲームロジック
    ├── speech.js    ← 音声読み上げ
    └── timer.js     ← タイマー
```

## 動作確認チェックリスト

### 基本動作
- [ ] `index.html` をブラウザで開くとTOPページが表示される
- [ ] 3つのパートボタン（順唱・逆唱・整列）が表示される
- [ ] パートを選択するとルール説明が表示される

### 音声読み上げ
- [ ] 「開始」ボタンを押すと数字が日本語で読み上げられる
- [ ] 読み上げ中は入力フォームが無効（グレーアウト）になる
- [ ] 読み上げ終了後、カウントダウンが自動で始まる

### 回答・採点
- [ ] 入力フォームに数字のみ入力できる（文字は弾かれる）
- [ ] 回答ボタン押下で正誤判定される
- [ ] 画面下部に○または×が追記される

### 進級・打ち切り
- [ ] 同桁数2問とも不正解でパートが終了する
- [ ] 1問以上正解で次の桁数に進む
- [ ] 順唱9桁・逆唱8桁をクリアするとボーナスステージ（10桁〜）に進む
- [ ] ボーナスステージで2問連続不正解でパート終了する

### モバイル対応
- [ ] スマートフォンで開いたとき、入力フォームをタップするとテンキーが表示される
- [ ] 画面が横スクロールしない

### ナビゲーション
- [ ] Restartボタンで同パートの最初（練習）に戻る
- [ ] TOPに戻るボタンでパート選択画面に戻る

## ブラウザ別の注意事項

| ブラウザ | 注意点 |
|---------|--------|
| iOS Safari | 音声はユーザーのタップ操作（開始ボタン）から直接呼び出す必要がある |
| Firefox | Web Speech API は限定的にサポート。動作確認はChrome推奨 |
| Chrome | 最も安定して動作する。開発時の主ターゲット |

## Web Speech API 非対応ブラウザでのテスト

非対応ブラウザでは「このブラウザは音声読み上げに対応していません」のエラーメッセージが表示される。  
テスト中にSpeech APIを無効化したい場合は、`speech.js` の `isSupported()` を `false` を返すよう一時変更する。
